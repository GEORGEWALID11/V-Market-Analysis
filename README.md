# 🛍️ V Market Analysis | Excel Dashboard

## 📌 Project Overview

V Market Analysis is a data analytics project developed using Microsoft Excel to explore customer shopping behavior and evaluate business performance through data analysis and visualization

The project analyzes customer transactions to uncover valuable insights into purchasing patterns revenue distribution and product performance

## 📊 Dataset Overview

The dataset contains information about

- Customer demographics
- Product categories
- Shopping quantities
- Product prices and total revenue
- Payment methods
- Shopping malls
- Invoice dates and monthly trends

## 🔍 Key Analysis Areas

- Customer distribution by gender
- Revenue by product category
- Sales performance across shopping malls
- Customer purchasing behavior
- Payment method distribution
- Product quantity analysis
- Monthly sales trends

## 🛠️ Tools and Technologies

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Interactive Dashboards

## 🎯 Project Objectives

- Understand customer purchasing behavior
- Identify the best performing product categories
- Analyze revenue across shopping malls
- Evaluate payment preferences
- Discover shopping trends
- Generate actionable business insights
